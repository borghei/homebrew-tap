# Homebrew Tap

Homebrew formulae for tools by [Amin Borghei](https://github.com/borghei).

## Install

```bash
brew tap borghei/tap
brew install ink
```

## Available formulae

| Formula | Description |
|---------|-------------|
| [ink](https://github.com/borghei/ink) | A terminal markdown reader that actually looks good |
